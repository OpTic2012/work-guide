WORK GUIDE - ΦΩΤΟΓΡΑΦΙΚΟ UI + ΑΝΑΓΝΩΡΙΣΗ ΣΥΣΚΕΥΗΣ

Ανέβασε στο παλιό GitHub repository work-guide τα εξής 6 αρχεία από το μικρό update ZIP, απευθείας στο root:
  index.html
  procedures.js
  procedures.css
  wg-photo-ui.css
  wg-photo-ui.js
  sw.js

ΜΗΝ ανεβάσεις/αντικαταστήσεις το υπάρχον content.enc. Ο κωδικός που ήδη χρησιμοποιείς δεν αλλάζει.
Μην διαγράψεις τα icons/ ή το manifest.webmanifest.

Άνοιξε στο iPhone το εικονίδιο Work Guide. Στην πρώτη εκτέλεση μετά την ενημέρωση μπορεί να σου ζητήσει τον υπάρχοντα κωδικό. Στις επόμενες εκκινήσεις το αποθηκευμένο μη εξαγώγιμο κρυπτογραφικό κλειδί από την IndexedDB θα ξεκλειδώνει αυτόματα το app.

Για να ζητά ξανά κωδικό: Προφίλ -> Κλείδωμα αυτής της συσκευής. Αν διαγραφούν δεδομένα εφαρμογής ή αλλάξει ο κωδικός του encrypted content, θα ζητηθεί ξανά κωδικός.

ΠΡΟΣΟΧΗ: Αν κάποιος έχει πρόσβαση στο ξεκλείδωτο iPhone, μπορεί να ανοίξει την εφαρμογή χωρίς κωδικό. Το GitHub Pages παραμένει δημόσιο, και η παλιά μη κρυπτογραφημένη έκδοση παραμένει στο ιστορικό του δημόσιου repository.
Οι διαδικασίες παραμένουν τοπικές και κρυπτογραφημένες με το κλειδί του περιεχομένου. Αν διαγράψεις τα δεδομένα του iPhone ενδέχεται να χαθούν.

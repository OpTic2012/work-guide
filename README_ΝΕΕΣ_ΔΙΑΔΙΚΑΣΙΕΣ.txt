WORK GUIDE — ΔΙΑΔΙΚΑΣΙΕΣ ΑΠΟ ΤΟ iPHONE (ΑΣΦΑΛΗΣ ΕΚΔΟΣΗ)

ΤΙ ΕΧΕΙ ΑΛΛΑΞΕΙ
- Στην ενότητα «Διαδικασίες» εμφανίζεται «+ Νέα διαδικασία».
- Ορίζεις τίτλο, προαιρετική περιγραφή και όσα βήματα θέλεις.
- Αποθήκευση, άνοιγμα, επεξεργασία, διαγραφή και αλλαγή σειράς βημάτων.
- Οι προσωπικές διαδικασίες εμφανίζονται και στην Αναζήτηση.
- Τα προσωπικά δεδομένα αποθηκεύονται ΚΡΥΠΤΟΓΡΑΦΗΜΕΝΑ τοπικά στο συγκεκριμένο iPhone με το κλειδί της τρέχουσας συνεδρίας ξεκλειδώματος, όχι στο GitHub.

ΑΝΑΒΑΘΜΙΣΗ ΣΤΟ ΥΠΑΡΧΟΝ GITHUB
1. Κατέβασε το ZIP και αποσυμπίεσε το.
2. Στο υπάρχον repository work-guide κάνε Add file > Upload files.
3. Ανέβασε τα αρχεία index.html, procedures.js, procedures.css, sw.js.
4. Αν το GitHub δεν αντικαταστήσει τα υπάρχοντα, χρησιμοποίησε τον editor του GitHub ή κάνε git push.
5. ΜΗΝ αντικαταστήσεις το content.enc αν έχεις ήδη αλλάξει κωδικό. Το υπάρχον content.enc συνεχίζει να λειτουργεί.
6. Αν χρειάζεσαι το αρχικό content.enc από το ZIP, βεβαιώσου πρώτα ότι χρησιμοποιείς τον αρχικό κωδικό.
7. Περίμενε να δημοσιευτεί και κλείσε/άνοιξε το Work Guide, ώστε να πάρει την νέα έκδοση.

ΣΗΜΑΝΤΙΚΟ
- Η εφαρμογή παραμένει πίσω από τον υπάρχοντα κωδικό.
- Οι διαδικασίες που δημιουργείς στο iPhone ΔΕΝ εμφανίζονται αυτόματα σε άλλο κινητό, δεν βρίσκονται στο GitHub και μπορεί να χαθούν αν σβήσεις δεδομένα Safari/PWA ή την εφαρμογή.
- Επειδή η τοπική αποθήκευση είναι κρυπτογραφημένη με το κλειδί της τρέχουσας έκδοσης, αν αλλάξεις τον κωδικό/content.enc, δεν θα μπορείς να ξεκλειδώσεις τις ήδη αποθηκευμένες τοπικές διαδικασίες. Φρόντισε να καταγράψεις/κρατήσεις αντίγραφο πριν την αλλαγή.
- Πρόκειται για στατική PWA, χωρίς κεντρικό server ή συγχρονισμό.
- Μην αποθηκεύεις εμπιστευτικές ή ευαίσθητες πληροφορίες της δουλειάς σε δημόσιες υπηρεσίες χωρίς σχετική άδεια.
- Παλαιότερες μη κρυπτογραφημένες εκδόσεις παραμένουν στο δημόσιο ιστορικό του GitHub.

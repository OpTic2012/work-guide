WORK GUIDE — ΠΡΟΣΤΑΤΕΥΜΕΝΗ ΕΚΔΟΣΗ iPHONE PWA

Για νέα δημοσίευση:
1. Δημιούργησε ΝΕΟ repository στο GitHub (π.χ. work-guide-locked). Το προηγούμενο repository περιέχει μη κρυπτογραφημένο υλικό στο ιστορικό των commits.
2. Κάνε εξαγωγή του ZIP και ανέβασε ΜΟΝΟ τα περιεχόμενα αυτού του φακέλου στο root του νέου repository.
3. Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. Άνοιξε το HTTPS site στο Safari του iPhone και επέλεξε Προσθήκη στην οθόνη Αφετηρίας.
5. Εισάγεις τον ξεχωριστό κωδικό που παρέχεται στη συνομιλία, ΟΧΙ σε αυτό το ZIP.

ΣΗΜΑΝΤΙΚΟ
- Ο κωδικός δεν βρίσκεται σε κανένα αρχείο του ZIP. Το περιεχόμενο του app είναι AES-256-GCM κρυπτογραφημένο και το κλειδί προκύπτει από τον κωδικό με PBKDF2-SHA256 (250.000 iterations).
- Ο δημόσιος κώδικας, τα εικονίδια, οι τίτλοι και τα metadata είναι προσβάσιμα. Μόνο το κρυπτογραφημένο περιεχόμενο δεν είναι αναγνώσιμο χωρίς κωδικό.
- Δεν είναι σύστημα λογαριασμών χρηστών, δεν έχει καταγραφή, ανάκληση πρόσβασης ή server authorization. Όποιος γνωρίζει τον κοινό κωδικό μπορεί να το ανοίξει. Αν τον μοιραστεί, δεν μπορείς να το αποτρέψεις χωρίς νέα έκδοση/κωδικό.
- Ο ΠΑΛΙΟΣ δημόσιος ιστότοπος και το ιστορικό του παραμένουν προσβάσιμα. Για απόλυτη αποφυγή παλιάς δημόσιας έκθεσης σταμάτα το παλιό GitHub Pages και αφαίρεσε/διέγραψε το παλιό repository. Η διαγραφή δεν αναιρεί αντιγραμμένα δεδομένα.
- Μη βάζεις πραγματικά εταιρικά ή εμπιστευτικά δεδομένα χωρίς έγκριση και κατάλληλο σύστημα κεντρικού ελέγχου πρόσβασης.

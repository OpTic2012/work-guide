WORK GUIDE — BASE UI v1 (iPhone PWA)

Αυτή η ενημέρωση φέρνει το UI κοντά στην εγκεκριμένη εικόνα (μωβ κεφαλίδες, έξι παστέλ κάρτες, λίστα διαδικασιών, αριθμημένα βήματα).
Διατηρεί τον κωδικό και την απομνημόνευση στο ίδιο iPhone, καθώς και την τοπικά κρυπτογραφημένη αποθήκευση προσωπικών διαδικασιών.

ΤΡΟΠΟΣ ΕΝΗΜΕΡΩΣΗΣ
1. Στο GitHub άνοιξε το υπάρχον Public repository work-guide.
2. Add file -> Upload files. Ανέβασε τα ΕΞΙ αρχεία του φακέλου αυτής της ενημέρωσης (όχι το ZIP):
   index.html, procedures.js, procedures.css, wg-photo-ui.css, wg-photo-ui.js, sw.js
3. Βεβαιώσου ότι βρίσκονται δίπλα στο content.enc στην αρχική διαδρομή (root).
4. Commit changes στο main branch.
5. Όταν ολοκληρωθεί το Pages deployment, άνοιξε στο Safari ή από το εικονίδιο. Αν δείχνει παλιό design, κλείσε πλήρως την εφαρμογή και άνοιξε ξανά online.

ΠΡΟΣΟΧΗ
- ΜΗΝ ανεβάσεις το παλιό HTML από κάποιο preview ή τα αρχεία του Designer. ΜΗΝ αντικαταστήσεις, διαγράψεις ή επανακρυπτογραφήσεις το content.enc για αυτή την αλλαγή.
- ΜΗΝ σβήσεις δεδομένα Safari, εικονίδιο PWA ή localStorage: προσωπικές διαδικασίες αποθηκεύονται στο iPhone σου και μπορεί να χαθούν.
- Το repo παραμένει δημόσιο. Κρυπτογράφηση προστατεύει μόνο το νέο περιεχόμενο που βρίσκεται στο content.enc και τις προσωπικές διαδικασίες. Δεν κάνει ιδιωτικό το ιστορικό GitHub.
- Αν άλλαξες κωδικό και κρυπτογράφησες ξανά το content.enc, οι παλιές προσωπικές διαδικασίες μπορεί να μην αποκρυπτογραφούνται λόγω διαφορετικού κλειδιού — αυτή η ενημέρωση δεν το αλλάζει.
- Όταν θυμάται τη σύνδεση, όποιος ανοίξει το ξεκλείδωτο iPhone μπορεί να μπει στο Work Guide. Στο Προφίλ (σύνδεσμος κάτω από τις έξι κάρτες) υπάρχει Κλείδωμα αυτής της συσκευής.

Η φωτογραφία είναι στόχος του design και όχι screenshot πραγματικής εγκατάστασης σε iPhone.

# Work Guide — iPhone PWA (έκδοση 1.0.0)

Το project είναι μια **πραγματική PWA**, όχι .ipa / εφαρμογή από App Store.
Ανοίγει στο Safari και μπορεί να προστεθεί στην οθόνη Αφετηρίας σαν app.
Δεν χρειάζεται Ubuntu, Mac, Xcode, Kivy ή Android Studio.

## Τι περιλαμβάνει

- Το ίδιο βασικό design και τα **ίδια 6 γραμμικά εικονίδια** του mockup.
- Αρχική, ενότητες, λειτουργική αναζήτηση, οδηγό βημάτων, FAQ, αγαπημένα.
- Αγαπημένα και προσωπικές σημειώσεις που αποθηκεύονται **τοπικά στη συσκευή**.
- Εικονίδιο iPhone (`apple-touch-icon.png`), `manifest.webmanifest`, `sw.js` για offline χρήση.
- **Ενδεικτικά** εταιρικά δεδομένα, όχι πραγματικές πληροφορίες εργασίας.
- Μηδενικές εξωτερικές βιβλιοθήκες, απαιτήσεις ή trackers.

## 1. Τοπική προεπισκόπηση στα Windows

Άνοιξε `index.html` με Chrome/Edge για την οθόνη. Για δοκιμή service worker:

1. Εγκατάστησε Python αν δεν υπάρχει (https://www.python.org/downloads/).
2. Κάνε διπλό κλικ στο `preview_windows.bat` (ή PowerShell στον φάκελο: `py -m http.server 8000`).
3. Άνοιξε `http://localhost:8000/` στο browser στον ίδιο υπολογιστή.

**Σημείωση:** Μόνο η δοκιμή μέσω `localhost`/HTTPS ενεργοποιεί τον offline service worker.

## 2. Ανέβασμα στο GitHub Pages από Windows

ΠΡΟΣΟΧΗ: το GitHub Pages είναι δημόσιο. Ανέβασε **μόνο το demo / μη εμπιστευτικά στοιχεία**.
Το αρχείο `robots.txt` δεν παρέχει προστασία ή ιδιωτικότητα.

1. Κάνε λογαριασμό στο https://github.com, εάν δεν έχεις.
2. Πάτησε `+` > `New repository`. Δώσε π.χ. `work-guide-iphone` και επίλεξε **Public**.
3. Από `Add file` > `Upload files` ανέβασε τα **περιεχόμενα του φακέλου** (όχι το ZIP), ώστε το `index.html` να είναι στο root. Σύρε και το φάκελο `icons`.
4. `Commit changes`.
5. `Settings` > `Pages` > `Build and deployment` > `Deploy from a branch`.
6. `Branch: main` και `/(root)` > `Save`.
7. Άνοιξε τη διεύθυνση που θα εμφανιστεί, περίπου `https://TO-ONOMA-SOU.github.io/work-guide-iphone/`.

Αν δεν εμφανίζεται η σελίδα, έλεγξε ότι `index.html`, `sw.js`, `manifest.webmanifest` και `icons/` βρίσκονται στον ίδιο δημοσιευμένο φάκελο.

## 3. Εγκατάσταση στο δικό σου iPhone

1. Άνοιξε την **HTTPS** διεύθυνση στο **Safari**.
2. Πάτησε **Κοινοποίηση** (σε νεότερο iOS: Μενού σελίδας > Κοινοποίηση).
3. Επίλεξε **Προσθήκη στην οθόνη Αφετηρίας**.
4. Κράτησε ενεργό το **Άνοιγμα ως Web App** και πάτησε **Προσθήκη**.
5. Πάτησε το μπλε-μωβ εικονίδιο `Work Guide` από την αρχική.
6. Άνοιξέ το **μία φορά online** ώστε να αποθηκευτεί το περιεχόμενο για offline χρήση.

## Επεξεργασία

- Η εμφάνιση/περιεχόμενο ζει στο `index.html` (μεταβλητές `sections`, `steps`, `faqs`, `contentFor`).
- Τα εικονίδια είναι διανυσματικά SVG μέσα στη μεταβλητή `vectorPaths` ώστε να ταιριάζουν με τη μακέτα.
- Για να αλλάξεις στατικό περιεχόμενο, επεξεργάσου το `index.html`, κάνε νέο commit και άλλαξε την τιμή CACHE στο `sw.js` (π.χ. `workguide-pwa-v1.0.1`) για ασφαλή ανανέωση.
- Οι προσωπικές σημειώσεις και τα αγαπημένα διατηρούνται μόνο σε αυτό το iPhone και **δεν συγχρονίζονται**.
- Μην καταχωρείς κωδικούς ή ευαίσθητα εταιρικά δεδομένα. Η τοπική αποθήκευση δεν είναι κρυπτογραφημένη.

## Τεχνικά

Το PWA frontend είναι HTML/CSS/JavaScript, **όχι Python/Kivy**. Αυτή είναι η απλούστερη λύση για χρήση σε iPhone χωρίς Mac. Αν στο μέλλον θέλεις σύνδεση με εταιρικά συστήματα, μπορούμε να προσθέσουμε Python backend (FastAPI) με ασφαλή πρόσβαση.

Η δημιουργία αρχείων εδώ **δεν σημαίνει** ότι η PWA ανέβηκε ήδη online ή εγκαταστάθηκε στο iPhone. Το τελικό βήμα δημοσίευσης γίνεται από εσένα στο GitHub Pages (ή σε άλλο HTTPS hosting).
